GUI 터미널 버퍼 — MuShell 창 (window index 1) 전용

sys_write(fd=1/2, ...) 호출 시 이 버퍼에 텍스트가 쌓이고, repaint()가 호출되면 창 1의 콘텐츠 영역에 렌더링된다.

§처리하는 제어 문자

  • \n (0x0A): 줄 바꿈 + 스크롤
  • \r (0x0D): 커서를 줄 처음으로
  • \x08 (0x08): 커서 왼쪽 이동 (backspace)
  • \x1B (ESC): ANSI 시퀀스 skip (단순 무시)
