MuWM — 인터랙티브 창 관리자 (BETA 2)

§이벤트 흐름

mouse::IRQ12 → process_packet() → on_click / on_drag / on_release → wm

§기능

  • 창 드래그 (타이틀바 홀드+이동)
  • 닫기 버튼 (X) → 창 숨기기
  • MuStart 클릭 → 모든 창 원래 위치로 복원
  • 포커스 강조 (타이틀바 색상 변경)
