BETA 4: Capability Handle Table ↔ 실제 fd 경로 연결

§설계

sys_open()  →  FileResource / DirResource
                    ↓
             HandleTable::insert()  →  fd (u32)
                    ↓
sys_read/write/lseek/close(fd)
    →  HandleTable::get::<FileResource>(fd)
    →  데이터 읽기 / 위치 이동 / Arc 참조 해제

§전역 싱글턴

커널은 한 번에 프로세스 하나만 실행하므로, 전역 FD_TABLE 하나로 충분. init() 은 새 프로세스 시작 시 테이블을 초기화한다.

§SAFETY

FdTableCell은 UnsafeCell로 내부 가변성을 제공. 싱글코어 + 시스템콜 핸들러 비재진입 → 실제 경쟁 없음.
