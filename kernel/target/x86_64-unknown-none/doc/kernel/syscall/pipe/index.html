BETA 3: pipe / pipe2 / select / epoll

§pipe

커널 링 버퍼(4 KB) 1개를 동시에 지원. sys_pipe가 호출될 때마다 read-fd / write-fd 쌍을 채번해 반환.

§select

  • fd 0 (stdin) : 키보드 버퍼에 데이터가 있으면 읽기 준비
  • fd 1/2 : 항상 쓰기 준비
  • pipe read fd : 파이프 버퍼에 데이터가 있으면 읽기 준비
  • timeout NULL : 블로킹(데이터 올 때까지 HLT)
  • timeout {0,0}: 비블로킹

§epoll

최대 16개 fd 감시. EPOLL_CTL_ADD/MOD/DEL 지원. epoll_wait 는 ready fd가 생길 때까지 HLT.
