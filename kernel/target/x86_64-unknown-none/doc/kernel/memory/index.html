메모리 서브시스템 (Memory Subsystem)

§초기화 순서

memory::init(hhdm_offset, memmap_entries)
  ├── HHDM_OFFSET 전역 저장
  ├── frame::init()   → 물리 프레임 비트맵 구성
  └── heap::init()    → 커널 힙 활성화 (이후 Box/Vec 사용 가능)

§HHDM (Higher Half Direct Map)

limine은 부팅 시 물리 메모리 전체를 상위 절반 가상 주소에 직접 매핑함. 가상 주소 = 물리 주소 + HHDM_OFFSET

이를 통해 물리 주소를 알고 있으면 어떤 메모리든 가상 주소로 접근 가능. 커널 힙, 페이지 테이블 조작 등 모든 물리 메모리 접근에 사용됨.
