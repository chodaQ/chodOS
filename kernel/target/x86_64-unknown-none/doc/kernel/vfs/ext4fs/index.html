ext4 읽기 전용 드라이버 (ALPHA 8)

§설계

ext4-view 크레이트를 사용해 커널에 embed된 ext4 이미지를 읽는다. 이미지는 include_bytes!로 커널 바이너리에 포함됨 (휘발성 없음).

§Ext4Read 구현

ext4-view는 Box<dyn Ext4Read> 인터페이스를 통해 데이터를 읽는다. StaticSlice가 &'static [u8]에 대해 Ext4Read를 구현한다.

§경로 규칙

ext4-view의 Path는 /로 시작하는 절대 경로를 받는다. 예: /etc/os-release, /var/log/boot.log
