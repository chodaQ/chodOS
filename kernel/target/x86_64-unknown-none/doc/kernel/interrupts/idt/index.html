IDT (Interrupt Descriptor Table) 설정

§IDT 게이트 디스크립터 (16바이트)

bits 0:15   = handler[15:0]
bits 16:31  = 코드 세그먼트 셀렉터 (CS = 0x08)
bits 32:34  = IST 인덱스 (0 = 전용 스택 없음)
bits 35:39  = 예약 (0)
bits 40:47  = 타입 + 속성
                0x8E = 인터럽트 게이트 (IF 클리어, 하드웨어 IRQ에 사용)
                0x8F = 트랩 게이트    (IF 유지,   CPU 예외에 사용)
bits 48:63  = handler[31:16]
bits 64:95  = handler[63:32]
bits 96:127 = 예약 (0)

§인터럽트 게이트 vs 트랩 게이트

인터럽트 게이트 (0x8E): 진입 시 RFLAGS.IF = 0 (인터럽트 비활성화) → 하드웨어 IRQ: 핸들러 실행 중 같은 IRQ가 재진입하는 것을 방지

트랩 게이트 (0x8F): RFLAGS.IF 변경 없음 → CPU 예외: 예외 핸들러 안에서도 다른 인터럽트 허용 (디버깅 편의)
