트랩 게이트 DPL=3: ring3의 int 0x80 소프트웨어 인터럽트 허용 DPL이 3이어야 ring3 코드가 int 0x80을 발생시킬 수 있음. DPL=0이면 ring3에서 int 0x80 시 #GP 발생.
