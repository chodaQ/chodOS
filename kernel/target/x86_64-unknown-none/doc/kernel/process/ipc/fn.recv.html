Function recv

pub fn recv() -> Option<Message>
Expand description

메시지 수신 (현재 프로세스의 큐에서 꺼냄)

§반환값

  • Some(Message): 수신된 메시지
  • None: 큐가 비어있음 (메시지 없음)

§비고

논블로킹: 큐가 비면 바로 None 반환. 블로킹이 필요하면 호출자가 직접 루프+yield 패턴을 써야 함:

loop {
    if let Some(msg) = ipc::recv() {
        // 처리
        break;
    }
    scheduler::yield_now(); // 메시지 올 때까지 다른 프로세스에 양보
}
