pub fn send_cap(from: u64, to: u64, cap_id: u64) -> bool
Expand description

Capability 전달 — 기존 IPC 채널을 통해 cap_id를 수신자에게 전송.

cap_id를 8바이트 데이터로 포장해서 기존 메시지 큐에 넣음. 데이터 자체는 SHARED_BUFFERS에 그대로 있음 — 복사 없음.
