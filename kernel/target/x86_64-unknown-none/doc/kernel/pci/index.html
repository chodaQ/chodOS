PCI 설정 공간 접근 (Config Mechanism #1)

CONFIG_ADDRESS (0xCF8): 버스/디바이스/함수/오프셋 선택 CONFIG_DATA (0xCFC): 선택된 레지스터 읽기/쓰기

포트 I/O 헬퍼(outl/inl/outw/inw/outb/inb)도 여기서 제공.
